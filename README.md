# Jarvis

面向个人的可视化 AI 助手。当前 HUD v0.3 已冻结为模拟展示壳；当前优先开发 Jarvis，陪伴通道暂时保留。B1/B2 核心与 Jarvis 合成邮件领域服务已编码；现有待办等接口已通过本机 HTTP 合成数据验证；新近领域服务尚未全部接入接口。API 使用本地 bearer token 门禁，尚无完整账户登录或个人数据加密，也未连接真实账号，只能使用合成数据。

## 底层演示

[本机启动说明](docs/START_HERE.md) 提供不需要安装第三方依赖的临时合成数据演示。演示不是完整 AI 助手；资料在进程退出后清理，不连接任何真实账号。

## 预览

在文件管理器中双击 [`preview.html`](preview.html)，或将其拖入浏览器。无需 Python、依赖安装或本地服务。当前为 v0.3 增量 A 原型：可切换陪伴助手与 Jarvis、独立会话、生成续聊卡、查看/改写/禁记/删除/分享记忆、收集内容、审批带载荷哈希的草稿；原型数据写入浏览器 localStorage，刷新不丢；请只使用虚构数据，因为这里没有个人资料加密。

**快速自检：** `preview.html?selftest=1` 跑 12 项单元自检，`preview.html?e2e=1` 跑 12 项交互自检（真实浏览器点击），`preview.html?page=记忆&assistant=companion` 直达指定页面。人工验收清单见 [`docs/PLAN.md`](docs/PLAN.md) 的 §7.4。

## 已确认方向

- 核心价值：统一个人信息与行动中枢。
- 首版重点：邮件和待办做完整主流程；X 与知识库先做轻量收集/浏览/整理入口。
- 平台目标：Windows 桌面体验 + Jarvis 网站登录 + 多设备使用；密钥恢复/设备撤销协议待设计。
- 隐私：本地优先、跨设备端到端加密、云端只存内容密文；向云模型发送必要内容前明确告知。
- 收集：统一收集箱接入微信、X、浏览器、小红书、邮件及其他应用；每个来源按官方 API 或主动分享/剪藏/粘贴实现。
- 自动化：可逆整理动作可按用户规则执行；邮件发送等外部沟通逐项确认。
- 交互：鼠标/键盘 + 按键启动语音输入与播报；不常驻监听。
- HUD：中央核心、环绕信息舱、青蓝与琥珀光效。
- 长期技术方向：React + Vite + TypeScript 前端，Python + FastAPI 后端；当前先完成 FastAPI + SQLite 本地核心，前端暂缓扩展。
