# 实验性合成加密库

状态：仅供虚构数据测试；与 Jarvis 现有数据库完全分离，不能用于个人资料。2026-11-07。

## 做了什么

backend/experimental/synthetic_vault.py 在 Windows 上要求显式 synthetic 模式和可用 SQLCipher 驱动，在新目录生成随机 32 字节实验密钥，用当前 Windows 用户范围 DPAPI 包装后保存到 key.dpapi；实验数据库 vault.db 使用 SQLCipher 和 WAL。初始化先写隔离临时目录，成功后再重命名；目标已存在时拒绝覆盖。打开已有库时必须找到包装密钥并成功解锁，缺驱动、错误密钥或普通 SQLite 驱动不会回退明文。

backend/verification/verify_synthetic_vault.py 在临时目录用虚构标记验证：合成门禁、目标不覆盖、初始化失败清理、正确密钥读写与进程重启、错误密钥和普通 SQLite 拒读、主库与 WAL 标记扫描、事务异常回滚、损坏密钥拒绝及伪装的普通 SQLite 驱动拒绝。正常权限下已通过。SQLCipher 在错误密钥测试时可能输出预期的 HMAC 错误日志，不应包含密钥。

## 明确限制

- app/database.py 仍使用标准明文 SQLite；此实验未接入 API、迁移器、真实资料或同步服务。模式开关无法识别输入是否真实。
- 当前使用本机发现的 sqlcipher3-wheels 0.5.7（SQLCipher 4.12.0 community）测试，发行物来源、构建、维护、安全和完整许可证尚未独立审查，也没有固定为正式依赖。
- DPAPI 通常绑定 Windows 用户和设备；实验没有换机恢复、恢复口令、备份、密钥轮换、跨用户或系统损坏后的测试。丢失 Windows 用户密钥材料可能无法恢复。
- 初始化失败的普通异常已测；进程强杀、掉电、磁盘故障、目录竞态、系统 ACL、所有临时文件、备份以及系统日志未验证。已知标记扫描不是完整保密证明。
- Python 和底层库可能保留密钥的内存副本；少量原生缓冲区清零不代表全部密钥可被可靠擦除。同一已解锁 Windows 用户下的恶意程序也不在磁盘加密单独覆盖范围。
- Windows Junction 检查依赖 Python 是否支持相应 API；不应在不可信目录或存在恶意本地进程的环境中作为安全边界使用。

## 接入前工作

先审查驱动供应链和许可；制定可恢复的密钥与备份方案；验证数据库迁移、故障恢复、临时文件与应用级连接生命周期；再由独立安全审查确认。只有在真实资料门槛全部完成并得到用户授权后，才考虑将应用数据迁入加密存储。
