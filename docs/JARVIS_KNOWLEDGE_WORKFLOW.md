# Jarvis 合成收集与知识工作流 J2b

**状态：** 已实现并用合成数据验证；2026-11-06。

用户确认后，Jarvis 可保存手动输入的合成文本或仅保存链接到本地收集箱，搜索和调整收集状态；合成链接仅接受 .invalid 域名，不自动访问网络。用户确认后可以把收集项整理为知识条目，或手动创建知识条目；支持搜索、编辑、软删除与恢复。

收集项和知识条目可以经用户确认创建待办，待办保留来源 ID 和类型。跨用户或不存在的来源会被拒绝，创建与关联在同一事务中完成。原来源软删除或不存在时，来源标记不可用；恢复后可以再次追溯。软删除可恢复，并不等于安全擦除。

当前只处理合成数据；数据库未加密，没有浏览器插件、文件导入、自动网页抓取、模型总结或知识问答，也未增加 HTTP 路由。真实资料进入前需完成本地数据保护及相应验证。

验证脚本：backend/verification/verify_knowledge.py；使用临时数据库，覆盖确认、搜索、权限隔离、失败回滚、软删除/恢复、来源缺失和审计正文隔离。


2026-11-07：模拟收集、笔记、来源转待办和软删除/恢复已接本机 HTTP；只接受合成资料。删除和编辑、删除和创建关联笔记的竞争已串行化并验证。当前仍无真实网页抓取、文件导入或个人资料加密。

## J28：本地合成标签（2026-11-07）

收集项和知识笔记可添加/移除标签并按单个标签精确查找。标签首尾空白会去除，采用 Unicode NFC 和大小写折叠去重；同一对象保留首次显示名称，每项最多 20 个、每个最多 64 字符。控制字符和格式字符不可使用。重复添加或移除可安全重试；查找最多返回 100 条且不返回正文。

软删除时标签仍保留但不出现在搜索中，恢复后重新可见；这不构成永久删除。所有写入与当前 owner、对象状态核对同事务，仅 Jarvis 可用。模拟导出 v6 明确排除标签，尚无恢复功能。没有标签层级、批量管理、跨设备同步或真实数据加密。验证见 backend/verification/verify_knowledge_tags.py 与 verify_http.py。

## J30：本地虚构知识列表

收集箱与笔记可按更新时间倒序分页，支持文字查询和单个标签筛选，收集项可按 inbox/processed/archived 状态筛选。列表不返回正文；所有结果都限定当前 owner、Jarvis 和未删除对象。查询可匹配正文但不会在列表中展示正文。游标绑定条件但不提供跨页快照，SQLite 的大小写处理也不是完整 Unicode 搜索。仅合成数据，见 backend/verification/verify_knowledge_query.py。
