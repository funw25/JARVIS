# Jarvis 本地总览 J5

**状态：** 合成数据领域服务已实现并验证；无 HTTP 路由或 HUD 接入。

总览在一个只读数据库快照内统计当前用户的 Jarvis 未完成待办、需处理邮件、本地收集箱、知识条目、待审发送提案和待确认的本地模拟模型预览。列表只返回必要字段，不包含邮件正文、待办说明、知识正文、草稿正文、模型输入或其他用户资料。总览不执行模型、发送或整理。

调用方显式提供 UTC 偏移分钟，默认 UTC；系统据此将待办归为已逾期、今天、未来、无截止日期或无效日期。这个固定偏移方案尚不处理夏令时或时区规则变化，正式客户端应提供可验证的时区方案。每类列表有上限，统计数量仍为总数；当前实现会在内存中聚合本地数据，规模较大时需分页和性能评估。

测试 backend/verification/verify_overview.py 覆盖时区跨日、期限分类、数量与列表限制、owner 隔离、敏感正文不进入总览，以及参数校验。所有数据为临时合成数据；数据库加密、真实账号、模型和前端均未接入。

2026-11-07：总览的邮件、收集、笔记与审批统计由数据库计数并仅读取所需摘要；待办分类仍逐条扫描，但只在内存中保留有限数量的展示项。所有查询在同一读取事务中完成。1200 条各类虚构记录的统计、排序、返回数量和内容隔离检查通过；这不是生产负载或延迟基准。
