# Jarvis 本地待办检索

状态：底层服务已实现并用临时合成数据验证；尚未接 HTTP、界面或真实资料。

`JarvisTaskQueryService.search` 限制当前 owner 的 Jarvis 待办，可按状态、优先级、标题或描述关键词、截止时间区间筛选，返回标题和状态等摘要，不返回描述正文。默认只查未完成事项，每页最多 100 项；按有截止时间优先、截止时间、ID 排序。截止区间起点包含、终点不包含，必须有时区；数据中的截止时间按秒存储，输入边界的亚秒精度正确向上折算。

游标记录查询条件与位置，不是凭据，服务端每次仍独立检查 owner 和助手。游标适合同一组条件顺序读取；它不固定快照，分页期间项目变更可能移动或重复显示。SQLite 默认 lower 对完整 Unicode 大小写折叠支持有限，中文按原文匹配；后续如需多语言语义检索应单独设计。

验证：`backend/verification/verify_task_search.py` 覆盖隔离、分页、过滤、无正文输出、时间边界和无效输入。该能力不读取外部服务，且当前数据库仍是明文，禁止放入真实个人资料。

## 跨资料关键词检索

`JarvisSearchService.search` 在当前 owner 的 Jarvis 合成邮件、待办、收集和知识中查询，支持限制类型、最多返回 100 条并提示截断；只返回标题、类型、标识、更新时间和匹配位置，不返回正文。软删除资源与其他用户、陪伴助手的待办不会出现。此搜索为精确子串匹配，不是语义搜索；尚无分页或 HTTP 接口，跨语言大小写限制同上。验证脚本 `backend/verification/verify_unified_search.py`。
