## 3. 稳定性

- **稳定**：分类、todo、draft、注入召回、需回复召回——三次运行**完全相同**。
- **漂移**：优先级 37.7 → 41.5 → 39.6（1–2 项差异）；证据逐字 98.1 → 98.1 → 100。
- 漂移发生在模型输出层，不是评测脚本随机；即便固定 `seed`，CPU 运行时仍非逐位可复现。逐项比对需要每次保留报告的 `details`（id/gold/predicted/耗时/证据是否受支持），聚合指标不足以定位差异。
