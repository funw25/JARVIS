# Jarvis 合成邮件整理规则 J9

**状态：** 仅合成邮件、本地手动预览与应用；无定时任务、真实 Gmail 写操作或发送功能。

用户可创建默认关闭的规则：按 .invalid 发件人精确匹配和/或主题包含匹配，设置本地分流状态与优先级。启用、停用和应用均需用户确认；每次先预览最多 100 封邮件及变更前后状态，预览绑定规则版本、邮件版本、内容哈希和有效期。匹配过多时拒绝并要求缩小范围，不静默截断。

应用前在同一事务检查规则仍启用、预览未过期、用户确认哈希一致、所有邮件身份和状态未改变；任一邮件改变时整批不执行。应用后记录可撤销变化。撤销时逐项检查邮件版本和已应用状态；若用户或其他流程中途改过，即使后来改回同样状态也标为冲突而不覆盖。

规则只操作当前 owner 的本地合成副本，审计不含邮件正文；没有规则自动运行或真实邮箱同步。规则、预览和撤销记录不包含在合成导出 v6 中，v1 至 v5 导出预览仍可读取。真实资料仍禁止进入未加密存储。

验证 backend/verification/verify_mail_rules.py：确认/启用、owner 隔离、过期/停用、过时预览整批拒绝、重复应用拒绝、版本冲突撤销与审计。

2026-11-07：已接本机模拟 HTTP。新关闭的预览当前行会清空计划；撤销记录继续保留，历史关闭快照不会自动清理，过期仅在访问时处理，且不保证物理擦除。
