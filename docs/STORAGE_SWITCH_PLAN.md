## 2. 切换开关

- 现状：`JARVIS_STORAGE_ADAPTER` 未设置 → 明文 `sqlite3`；设置 `apswmc` + `JARVIS_APSWMC_KEY` → 实验加密适配器。
- 切换后：默认走加密；明文路径保留为显式降级开关（例如 `JARVIS_STORAGE_ADAPTER=sqlite3`）**仅用于只读诊断**，并且必须拒绝写入真实数据。
- 密钥来源：Windows 凭据管理器中的 DPAPI 包装（S1 的 `dek.dpapi`）；不得引入环境变量常驻明文密钥。

## 3. 数据迁移（明文 → 加密）

1. 停止所有写入（关闭应用与服务）；
2. 用 `app.database.connect()` 打开现有明文库，`VACUUM INTO` 生成一份只读快照作为回滚副本；
3. 创建新 vault（S1 `create_vault`），在 vault 内应用全部迁移（17 个）；
4. 逐表复制：按外键顺序从明文库读取、写入 vault，使用同一套 schema 校验；
5. 校验：每表行数、主键集合哈希、抽样内容哈希、`integrity_check`；
6. 记录迁移报告（表名、行数、耗时、哈希）到 `docs/`；
7. 切换开关并启动，跑 54 项回归 + 手工冒烟；
8. 保留明文快照 30 天只读，到期删除（文件系统层面不承诺安全擦除）。

**失败处理**：任何一步失败 → 保持开关为明文、删除半成品 vault、保留原库与快照。

## 4. 回滚

1. 停止服务；
2. 把开关改回明文（`JARVIS_STORAGE_ADAPTER` 清空或 `sqlite3`）；
3. 用 §3 的快照恢复（覆盖或改路径）；
4. 跑回归确认读写正常；
5. 保留 vault 作为只读副本，记录回滚原因。

回滚必须是**可演练的**：在 G7 通过前不得切换。

## 5. 验收清单（切换窗口内执行）

- [ ] 54 项回归在加密后端全绿
- [ ] 迁移报告行数与哈希一致
- [ ] `PRAGMA integrity_check` = ok
- [ ] 备份：切换后立刻做一次本地 + 一次云端备份
- [ ] 恢复：用该备份恢复到临时目录并读出一条已知记录
- [ ] 回滚：按 §4 演练一次，确认能回到明文
- [ ] 审计日志记录切换时间、`key_id`、备份 `backup_key_id`
