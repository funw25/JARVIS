# Jarvis 合成资料导出预览 J7

**状态：** 仅合成数据；无文件写入、无恢复、无加密。

本地服务构造当前 owner 的 Jarvis 合成邮件、草稿、收集项、知识条目、待办与可追溯来源的内存数据包；不扫描外部账号、不上传、不自动写文件。地址和链接仍限制在 .invalid 测试域名。

清单列出各类数量、被省略的待办来源、不可用的知识来源及不完整草稿数量。陪伴数据、会话、记忆、模型请求和建议、审批、审计、凭据、软删除项、模拟连接与同步运行记录不包含在内；同步导入的合成邮件可按普通合成邮件导出，但不保留模拟来源 ID。来源不可用时不导出其内容，知识条目关联改为无来源并计数。

预览只做格式、大小、字段、来源、测试地址和 SHA-256 校验，不写数据库；散列只用于发现意外损坏，攻击者可以重新计算散列，不能证明来源或防止恶意篡改。每类最多 10000 项、规范化内容最多 5 MB。导出建立事件只记录无正文的审计元数据。

这不是加密备份，也不能恢复。真实备份需先完成 J3 密钥管理、认证加密、备份恢复与版本迁移，并明确是否覆盖现有数据。软删除和已排除的领域不会因此被安全擦除。

验证脚本 backend/verification/verify_synthetic_export.py 覆盖 owner 隔离、导出范围与省略计数、损坏/伪造引用/非合成地址/多余字段拒绝及审计正文隔离。

导出清单当前为版本 6：不包含本地规则及其预览/撤销记录、待办重复提交记录、提醒规则、提醒确认记录或知识标签；预览仍接受版本 1 至 5。所有版本均不提供恢复。


## 输入预览边界（2026-11-07）

预览在 JSON 序列化前对输入规模、层次、值类型和 UTF-8 文本做上限检查，拒绝超大文本、循环/深层结构和非法 Unicode；完整序列化后仍验证 5 MB 上限。此检查不提供加密或来源真实性，也不能约束调用方在调用前读取巨型文件的内存占用；未来 HTTP/文件导入层仍须限制请求体及文件读取大小。验证见 `backend/verification/verify_synthetic_export.py`。
