# Jarvis 视觉与交互设计

**状态：** Accepted direction  
**版本：** 0.1  
**更新：** 2026-11-06

## 设计意图

界面应有电影 HUD 的空间感、能量感与环绕式信息层级，同时保持真实工作流的清楚与可信。Jarvis 是工作台，不是电影特效展示页：动态视觉必须关联助手状态、同步进度、待处理量或模型活动。

## 参考研究与原创边界

- [HALOFLUX](https://github.com/Ryder191/haloflux)：参考环形光场、分层粒子与不匀速运动的节奏；不复制其源代码、画面布局、图形素材或预设。其仓库当前标注 PolyForm Noncommercial License，故只作为视觉研究，不作为产品代码或资源依赖。
- [JARVIS Amber Protocol HUD](https://github.com/Gmasterzhangxinyang/jarvis-amber-protocol-hud)：参考琥珀色 HUD、浏览器内全屏呈现和多层信息面板；不复制专属素材或成品页面。项目 README 描述了摄像头、手势、地图和 Agent 作为该项目功能，不代表 Jarvis 需要这些功能。
- 采用清洁实现：自绘 CSS/SVG/Canvas 图层，原创组件、排版、动效、配色和图标。

## 视觉方向

- **画布：** 深空黑蓝背景，轻微网格/星尘，边缘使用低亮度的径向渐变。
- **主色：** 冰青与电蓝用于可操作和连接状态；琥珀用于警示、等待确认；柔白用于正文；灰蓝用于次要信息。
- **焦点：** 中央圆形“认知核心”由多层细环、扫描弧、短刻度和稀疏粒子组成。状态可为待机、分析、同步、需要确认、离线。
- **信息布局：** 左侧窄轨导航；顶部系统状态栏；中央核心区；两侧环绕邮件和任务舱；底部内容/审批带。内容密集度随窗口宽度自适应。
- **材质：** 细描边、半透明深色面板、少量辉光、等宽字用于状态码/时间/计数。正文避免全大写和过度字距。
- **避免：** 纯装饰性大光球占屏、所有组件都闪烁、红色泛滥、正文使用低对比荧光色、模拟现实摄像头扫描环境。

## 屏幕层级（桌面 16:9）

1. **导航轨：** 总览、对话、邮件、收藏、知识、任务、审批、记忆、收集（9 项，窄屏可折叠）；设置放在顶部系统栏的齿轮入口。
2. **系统栏：** 当前助手切换（陪伴 / Jarvis，身份常显）、Jarvis 状态、端到端加密同步状态、麦克风未启动提示、待审批计数、数据源连接状态、设置入口。
3. **中心核心：** 当前状态与今日工作负载的视觉焦点；环绕任务计数和短状态文本。
4. **左侧信息舱：** 优先邮件，显示来源、主题、摘要、建议原因和动作入口。
5. **右侧信息舱：** 今日任务、进度与快捷创建。
6. **底部数据带：** 最近收藏/知识条目与审批队列摘要。
7. **Capture Inbox：** 可从导航或全局快捷键打开；展示最近从浏览器和应用主动收集的内容及其来源。

## 主要交互

- 点击导航面板切换模块，提供当前模块高亮、面包屑和返回路径。
- 单击数据卡片进入详情；默认只展开摘要，原文按需查看。
- 搜索栏统一支持内容搜索；高级筛选留在对应模块。
- 中央核心通过状态改变反馈系统工作，不承载复杂操作。
- 按键启动语音时显示明确的录音状态、当前录音按键、识别文本预览和取消/完成入口；空闲时显示麦克风未启动。
- Capture Inbox 允许用户先快速收集、稍后整理；每条卡片都显示来源应用和捕获方式。
- 写操作在独立审批抽屉/对话框展示明确动作和完整载荷。
- 桌面提供全屏/退出全屏，不默认隐藏浏览器控件。
- 多设备同步显示加密状态和最近同步时间；冲突需要用户可理解的选择界面。

## 动效规范

- 核心待机：慢速光环呼吸，周期 8–12 秒，不闪烁。
- 正在分析/同步：显示可见进度、状态名和计时；动效速度上升，但状态完成后停止。
- 待审批：琥珀色静态强调与数量标签，不用警报闪烁。
- 页面切换：短暂淡入/位移 120–180ms。
- `prefers-reduced-motion` 开启时关闭粒子、视差、自动旋转，只保留静态状态环。
- 不播放背景音乐；未来音频功能必须为用户主动触发。

## 响应式与无障碍

- 桌面：目标 1440×900，兼容 1280×720；优先保证 16:9 主 HUD 的可读性。
- 平板：中心核心缩小，信息舱改为上下流；任务与审批始终优先可见。
- 手机：改为简洁单列状态面板；圆环只作页头标识，不保留密集环绕层。
- 正文和控件符合至少 WCAG AA 对比目标；状态不能只依赖颜色，还需文字或图标。
- 所有动效区域不抢焦点；支持键盘导航、明确焦点环和屏幕阅读标签。

## 当前原型的验收准则

- 打开首屏能立即看出这是 Jarvis 工作台，而非普通表格后台。
- 第一眼聚焦中央状态核心，第二眼能看到邮件、任务和审批数量。
- 用户可以在 5 秒内理解系统是否连接外部服务、是否有待审批动作。
- 不出现虚构的摄像头、麦克风、AI 在线监听或外部执行状态。
- 搜索、模块切换、任务勾选和演示审批仍可操作。
